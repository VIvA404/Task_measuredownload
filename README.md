# Замер скорости скачивания

Нужен Python 3.12 или новее. Скрипт использует стандартную библиотеку.

Запуск из этой папки

```bash
python download_benchmark.py "https://example.com/"
```

Подставьте прямой HTTP- или HTTPS-адрес файла. Скрипт последовательно делает 10 GET-запросов. Для каждого он открывает новое соединение и читает тело ответа до конца. Если запрос завершается ошибкой или сервер возвращает перенаправление, скрипт останавливается и сообщает номер запроса.

- Среднее время запроса выводится в секундах. Замер включает подключение, ожидание ответа и чтение тела.
- Общий объём — сумма размеров тел ответов в байтах.
- Скорость в МиБ/с — общий объём, делённый на суммарное время запросов. 1 МиБ равен 1 048 576 байтам.
